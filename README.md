# 28卒 ゲーム・CG就活カレンダー

<!-- README.md：このサイトの使い方（更新手順・ローカルでの確認方法・GitHub Pagesでの公開手順）をまとめたファイルです。 -->

大学のゲーム研究会メンバー向けに、28卒（2028年3月卒）のゲーム・CG業界のインターン・本選考の締切を一覧するサイトです。
ビルド不要の静的サイト（素のHTML・CSS・JavaScript）で、GitHub Pages で公開します。

## ファイル構成

| ファイル | 役割 | 更新時に触る？ |
| --- | --- | --- |
| `index.html` | ページの骨組み | 触らない |
| `style.css` | 見た目（色・レイアウト・ダークモード・スマホ表示） | 触らない |
| `app.js` | データを読み込んでタイムライン・カード・絞り込みを作る | 触らない |
| `data/schedule.json` | **日程データ** | **ここだけ書き換える** |
| `README.md` | この説明書 | 必要なら |

## 日程の更新手順

1. Claude に「検索して `data/schedule.json` を最新にして」と頼みます。
2. Claude が各社の公式ページなどを確認し、`data/schedule.json` だけを書き換えます。
   - 先頭の `updated_at` を更新した日にします。
   - 確認した項目は `checked_at` をその日にします。
   - 公式に書かれていない日付は `confidence` を `"要再確認"` か `"前年実績からの推測"` にします（画面に ⚠ が付きます）。
3. 下の「ローカルでの確認方法」で表示を確かめてから、GitHub に反映（コミット・プッシュ）します。数分で公開ページにも反映されます。

> 個人の選考状況など、メンバーに見せない情報は書かないでください。

### データの書き方（`data/schedule.json`）

```json
{
  "updated_at": "2026-11-11",
  "items": [
    {
      "id": "cygames-winter-1st",
      "company": "Cygames",
      "title": "冬インターン 第1次締切",
      "kind": "deadline",
      "start": "2026-11-27",
      "end": "2026-11-27",
      "time": "10:00",
      "category": "インターン",
      "roles": ["TA", "3DCG"],
      "houdini": false,
      "note": "対象はTA・3DCGほか",
      "url": "https://...（公式の募集ページ）",
      "source": "https://...（日付を確認したページ）",
      "checked_at": "2026-11-11",
      "confidence": "要再確認"
    }
  ]
}
```

| 項目 | 意味 |
| --- | --- |
| `id` | 一意な英数字の名前（重複しないように） |
| `company` / `title` | 会社名 / 表示名 |
| `kind` | `"deadline"`＝1日の締切（ひし形）、`"span"`＝応募受付期間（塗りつぶしバー。`end` を締切として数える）、`"event"`＝説明会・インターン実施期間など（枠だけのバー）、`"open"`＝受付中・締切未定（「受付中・締切未定」欄に出る） |
| `start`, `end` | `"YYYY-MM-DD"`。deadline は同じ日、open は `end` なし（`start` も不明なら省略可） |
| `time` | 締切時刻（任意、日本時間、例 `"10:00"`） |
| `category` | `"インターン"` / `"本選考"` / `"イベント"` / `"サークル"` |
| `roles` | 対象職種の配列。ここに書いた名前が「職種」の絞り込みに自動で並びます |
| `houdini` | 募集要項や記事で Houdini が明示されていれば `true` |
| `note` | 補足 |
| `url` / `source` | 公式の募集ページ / 日付を確認したページ |
| `checked_at` | 最後に確認した日 |
| `confidence` | `"確定"` / `"要再確認"` / `"前年実績からの推測"` |

JSON は最後の項目のあとにカンマを付けるとエラーになります。読み込めないときは画面上部にメッセージが出ます。

## ローカルでの確認方法

`index.html` をダブルクリックで開くと、ブラウザの制限でデータを読み込めません。簡単なサーバーを立てて開きます。

1. ターミナル（Windows は PowerShell）でこのフォルダに移動します。
2. 次のどちらかを実行します。
   - Python がある場合：`python -m http.server 8000`（Mac は `python3`）
   - VS Code の場合：拡張機能「Live Server」を入れて、`index.html` を右クリック →「Open with Live Server」
3. ブラウザで <http://localhost:8000/> を開きます。
4. スマホ表示は、ブラウザの開発者ツール（F12）でデバイス表示に切り替えるか、ウィンドウ幅を 760px 以下に狭めると確認できます。

確認用に、URL の末尾に `?today=2026-12-01` のように付けると、その日を「今日」として表示できます。

## GitHub Pages での公開手順

1. このフォルダの中身をリポジトリの直下（`index.html` が一番上にある状態）に置いてプッシュします。
2. GitHub のリポジトリページで **Settings → Pages** を開きます。
3. **Build and deployment** の **Source** を「Deploy from a branch」にし、**Branch** を `main`、フォルダを `/ (root)` にして **Save**。
4. 1〜2分待つと、同じ画面に公開URLが表示されます。これをサークルに共有します。

以降は `data/schedule.json` を更新してプッシュするたびに、自動で公開ページに反映されます。

## 画面の機能

- PC幅：左に項目名、右に月目盛りのタイムライン。締切はひし形、期間は角丸バー。今日の位置に点線、次の締切1件を赤で強調。行をクリックすると下に詳細（公式リンク・Googleカレンダー追加）が出ます。
- スマホ幅（760px 以下）：日付順のカード一覧（あと○日・時刻・対象職種・公式リンク）。
- 共通：最終更新日と次の締切までの日数、カテゴリ・職種・Houdini の絞り込み、締切済みを隠す切り替え、表示期間の前後移動（初期値は前月〜5か月先）、ライト/ダーク切り替え（初期値は端末の設定に合わせる）。
- 日付の計算はすべて日本時間です。
